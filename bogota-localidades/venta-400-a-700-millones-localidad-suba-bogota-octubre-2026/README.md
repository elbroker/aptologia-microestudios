# Qué se vende por entre COP 400 y 700 millones en la localidad de Suba, Bogotá — octubre 2026

Por entre COP 400 y 700 millones hay 1711 avisos únicos de venta en la localidad de Suba, Bogotá (mediana COP 550 millones).

Son el 17 % de toda la oferta de venta en la localidad de Suba, Bogotá.

Con ese presupuesto, el área mediana es 85 m² (en toda la oferta: 193 m²).

Lo más común son inmuebles de 3 habitaciones (54 % de los avisos con dato).

El 75 % son apartamentos y el 23 % casas.

Por metro cuadrado, la mediana es COP 6.272.727/m² (+7 % frente a COP 5.837.070/m²), puesto 8 de 18 localidades comparables.

El estrato más frecuente es 4.
