# Qué se vende por entre COP 700 y 1.200 millones en la localidad de Teusaquillo, Bogotá — octubre 2026

Por entre COP 700 y 1.200 millones hay 663 avisos únicos de venta en la localidad de Teusaquillo, Bogotá (mediana COP 900 millones).

Son el 28 % de toda la oferta de venta en la localidad de Teusaquillo, Bogotá.

Con ese presupuesto, el área mediana es 126 m² (en toda la oferta: 129 m²).

Lo más común son inmuebles de 3 habitaciones (45 % de los avisos con dato).

El 62 % son apartamentos y el 37 % casas.

Por metro cuadrado, la mediana es COP 7.032.258/m² (+5 % frente a COP 6.666.667/m²), puesto 3 de 17 localidades comparables.

El estrato más frecuente es 4.

- n = 663 avisos únicos · datos al 18 de octubre de 2026
