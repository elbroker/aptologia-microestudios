# Microestudios de vivienda — Colombia x10: Santa Marta (cruces de habitaciones, estrato y características) (octubre 2026)

466 microestudios abiertos de Aptología (aptologia.com) sobre precios de oferta de arriendo y venta de vivienda en Santa Marta, Colombia, cruzando barrio o ciudad con habitaciones, estrato, tamaño, parqueadero, baños, piso, antigüedad y características (amoblado, mascotas, conjunto, balcón), cada uno con al menos 30 avisos únicos (deduplicados entre portales). Cada carpeta trae un PDF de 2 páginas, un CSV con las cifras y una gráfica PNG.
