# Microestudios de vivienda — Bolivia x10 (cruces de habitaciones y características) (octubre 2026)

357 microestudios abiertos de Aptología (aptologia.com) sobre precios de oferta de arriendo y venta de vivienda en Bolivia, cruzando ciudad y zona con número de habitaciones, tamaño, estacionamiento y baños, cada uno con al menos 30 avisos únicos (deduplicados entre portales). Cada carpeta trae un PDF de 2 páginas, un CSV con las cifras y una gráfica PNG.
