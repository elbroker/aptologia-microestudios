# Microestudios de vivienda — Colombia x10: Pereira (cruces de habitaciones, estrato y características) (octubre 2026)

617 microestudios abiertos de Aptología (aptologia.com) sobre precios de oferta de arriendo y venta de vivienda en Pereira, Colombia, cruzando barrio o ciudad con habitaciones, estrato, tamaño, parqueadero, baños, piso, antigüedad y características (amoblado, mascotas, conjunto, balcón), cada uno con al menos 30 avisos únicos (deduplicados entre portales). Cada carpeta trae un PDF de 2 páginas, un CSV con las cifras y una gráfica PNG.
