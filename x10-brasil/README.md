# Microestudios de vivienda — Brasil x10 (cruces de habitaciones y características) (octubre 2026)

303 microestudios abiertos de Aptología (aptologia.com) sobre precios de oferta de arriendo y venta de vivienda en Brasil, cruzando ciudad y bairro con número de habitaciones, tamaño, estacionamiento y baños, cada uno con al menos 30 avisos únicos (deduplicados entre portales). Cada carpeta trae un PDF de 2 páginas, un CSV con las cifras y una gráfica PNG.
